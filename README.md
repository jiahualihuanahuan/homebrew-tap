# jiahualihuanahuan Homebrew Tap

Homebrew formulae for personal tools.

## Install oxpecker

```bash
brew tap jiahualihuanahuan/tap
brew trust jiahualihuanahuan/tap
brew install oxpecker
```

Or in one step after trusting:

```bash
brew install jiahualihuanahuan/tap/oxpecker
```

Oxpecker builds from source (requires Rust, which Homebrew will install automatically).
